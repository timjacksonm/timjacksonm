How I work

  1. 14 sessions coordinating multiple agents

    Orchestrate agents in parallel

    I run separate agents per repo and hand plans between them, so mobile and API changes move in lockstep instead of drifting apart.

  2. 3,765 shell commands run by agents

    Verify against real data

    I don't take a result on trust. Agents run the code, replay cached routes, query logs and cross-check public data feeds, and they revise findings when the evidence disagrees.

  3. 28 decisions Claude handed back to me

    Humans own the judgment calls

    Agents surface trade-offs and pause on product, data and deployment decisions. I make those calls myself, especially anything that is hard to undo.

  4. 56 pull requests merged

    Ship small, reviewed, green

    Work lands as focused pull requests with passing tests, typecheck and lint. I push back on tangents and verbose output until the code reads like it belongs.
